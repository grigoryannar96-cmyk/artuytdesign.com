# Artuyt Design Academy — Upwork Freelancer

A responsive Armenian course landing page for **Artuyt Design Academy** and its Upwork Freelancer program.

## Highlights

- Dark editorial visual system with Artuyt blue and yellow brand accents
- Animated hero video with cursor-responsive motion
- Course curriculum with expandable module topics
- Profession, format, bonus, instructor, pricing, and FAQ sections
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Project structure

- `index.html` — page markup
- `styles.css` — responsive layout, visual system, and animations
- `app.js` — course data and interactions
- `assets/` — brand media and imagery
